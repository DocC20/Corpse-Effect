# Corpse & Effect

A 2D platformer made for the **Bounce Back** game jam. Every death leaves your body behind as a trampoline. Fall, let go, and rise.

## Play on Windows
1. Click **CorpseAndEffect-Windows.zip** in the file list above, then click the **Download** button (the arrow, top right of the file view).
2. Right-click the downloaded zip → **Extract All**.
3. Double-click **CorpseAndEffect.exe**.
4. If Windows says "Windows protected your PC", click **More info → Run anyway**.

## Controls
- A / D or arrows: move
- W / Space / Up: jump (hold for higher)
- R: let go (leave a body you can bounce on)
- Shift / K / J: dash (unlocked on level 6)
- Esc: pause, F11: fullscreen
- Phones and tablets get on-screen buttons
